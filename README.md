# Crystallization

Crystallization is a Fabric mod for Minecraft Java Edition 1.21.11. While the
feature is enabled, right-clicking any not-yet-waterlogged block with regular
ice waterlogs the target and consumes one ice block. Ice remains the normal
stackable vanilla item (up to 64).

## Usage

- The feature is disabled on first launch.
- Press `Alt + F` in-game to enable or disable it. The primary key can be
  changed under Options > Controls > Key Binds > Crystallization.
- With Mod Menu installed, open Crystallization's configuration screen to
  switch the feature on/off or jump directly to the key-binding screen.
- Hold vanilla ice and use it on a dry waterloggable block such as a stair,
  slab, fence, or trapdoor.

The mod must be installed on both the client and server for multiplayer use.
Mod Menu is optional.

## Build

Run `./gradlew build` (`gradlew.bat build` on Windows). The distributable JAR
will be created in `build/libs`.
